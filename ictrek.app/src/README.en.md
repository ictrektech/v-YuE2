# v-YuE2 __APP_VERSION__

Free local song studio. No weights are bundled. Open through VOS, review model licenses, then let a model administrator request selected downloads through V-Scheduler from vivibit on ModelScope. Individual creator permission is not company commercial authorization. Songs and settings are private per account; shared models are managed in V-Scheduler.

https://github.com/ictrektech/v-YuE2

## Models and providers

Prepare models selects the recommended local files and downloads through V-Scheduler. Providers selects account-visible V-Scheduler models by writing, cover and speech-recognition capability. Configure all upstreams and provider credentials in V-Scheduler; the app does not store OpenRouter keys.

## Local compute admission

Native jobs start only after V-Scheduler grants a resource permit, respecting priority, budgets and stop requests. Resources return only after native exit and model unloading. Uncalibrated hardware, model sets and inputs are rejected. External cloud models pass through V-Scheduler without local compute permits while retaining user authorization and model visibility checks. See the project README for current calibration coverage; downloaded files do not authorize computation.
