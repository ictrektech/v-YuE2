# v-YuE2 __APP_VERSION__

免费本地歌曲创作工作台。安装包及镜像不含模型。请在 VOS 中打开应用，确认各模型许可后，由有模型管理权限的账户通过 V-Scheduler 从 vivibit 的 ModelScope 下载。个人创作者特许不等于企业商用授权。作品与设置按账户隔离；共享模型在 V-Scheduler 管理。

https://github.com/ictrektech/v-YuE2

## 模型与提供方

“准备模型”自动选择本机推荐文件，通过 V-Scheduler 下载到共享目录。“提供方”按写作、封面及语音识别能力选择 V-Scheduler 中当前账户可用的模型。供应商、密钥和上游地址统一在 V-Scheduler 配置；应用内不保存 OpenRouter 密钥。

## 本地计算调度

原生任务取得 V-Scheduler 的资源许可后才启动引擎，遵守优先级、资源预算与停止指令。任务退出并卸载权重后归还额度；未校准的硬件、模型组合及输入拒绝执行。外部云端模型由 V-Scheduler 默认放行，不占本机算力额度，但仍核验账户权限与模型可见性。当前本地生成校准范围及限制见项目 README；不能把模型下载完成视为已获计算授权。
